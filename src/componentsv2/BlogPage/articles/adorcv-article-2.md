# CV Standardization and Export with AdorCV: A Unified, Branded Format for Every Candidate

## How AdorCV converts CVs uploaded in various formats into consistent, exportable documents

One of the core functions of AdorCV, the AI application built to automate and streamline HR and recruitment tasks, is CV standardization. This article looks specifically at how AdorCV handles CV uploads, formatting, and exports — one of the features designed to help HR teams save time and improve efficiency across recruitment workflows.

### Uploading CVs in Various Formats

AdorCV allows users to upload candidate CVs in various formats. Instead of requiring HR teams to convert or clean up documents before adding them to the system, the application is built to accept CVs as they are received. This is one of the first ways AdorCV automates and streamlines HR and recruitment tasks: removing the manual step of preparing a document before it can be added to a company's system.

### Automatic Conversion into a Unified, Company-Branded Structure

Once uploaded, AdorCV automatically converts each CV into a unified, company-branded structure. This ensures consistency across all documents, regardless of how differently each candidate's original CV was formatted. Instead of a mix of layouts, fonts, and structures, HR teams end up with a consistent set of candidate profiles that follow the same branded template.

This consistency matters throughout the recruitment process. When every candidate profile follows the same structure, it becomes easier to review, compare, and store CVs without adjusting to a new layout each time.

### Fully Customizable Templates

The templates used for this standardization process are fully customizable. This means the unified structure applied to every CV can be adapted to match a company's specific branding and formatting requirements, rather than relying on a fixed, generic layout. As branding needs change, the templates used across AdorCV can be updated accordingly.

### Editing and Enriching Candidate Profiles

Standardization doesn't lock a profile in place. AdorCV includes tools to edit or enrich candidate profiles, so HR teams can update information, add details, or make corrections to a candidate's profile after it has been standardized. This keeps candidate documentation accurate even as new information becomes available over time.

### Exporting CVs: PDF, DOCX, or PPT

After a CV has been standardized, it can be exported as a PDF, an editable DOCX file, or a PPT file. This flexibility allows HR teams to choose the export format that best matches how the document will be used or shared.

#### PDF Export

A PDF export is useful when a finalized, non-editable version of a candidate profile is needed, for example when a document needs to be shared in a fixed, presentation-ready format.

#### Editable DOCX Export

An editable DOCX export allows the candidate profile to be further adjusted or customized after export, giving HR teams the flexibility to make additional changes outside of AdorCV if needed.

#### PPT Export

A PPT export presents the candidate profile in a presentation-style format, which can be useful when candidate information needs to be shared in a slide-based format.

### Multilingual Templates

AdorCV supports documents in both English and French. This means the standardized, customizable templates used for CV formatting are available for both languages, allowing HR teams to generate consistent candidate documentation regardless of which language is required for a given document or audience.

### How Standardization Connects to the Rest of AdorCV

CV standardization is closely connected to other features within AdorCV. Once a CV has been converted into AdorCV's unified structure, it becomes part of the searchable CV database with advanced filters, and it can also be included in AI matching against job descriptions in the dedicated Job Descriptions section. Standardized, structured data is what allows these other features to function effectively, since consistent formatting makes it easier for the system to organize and compare candidate information.

User-based login and role-specific permissions also apply to standardized CVs stored within AdorCV, meaning access to this structured candidate data remains controlled according to each user's role within the HR team.

### Benefits of Automated CV Standardization

- **Consistency across all documents**, since every CV follows the same company-branded structure
- **Time savings**, by removing the need to manually reformat each CV
- **Flexibility**, through fully customizable templates and multiple export formats
- **Up-to-date profiles**, thanks to tools for editing and enriching candidate information
- **Bilingual documentation**, with support for both English and French
