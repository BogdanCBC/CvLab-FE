# Managing Candidate Data in AdorCV: Search, Security, and Permissions

## A look at AdorCV's searchable CV database, advanced filters, and role-specific access controls

Storing and organizing candidate CVs is only useful if HR teams can find, manage, and protect that information effectively. AdorCV, the AI application built to automate and streamline HR and recruitment tasks, includes a searchable CV database with advanced filters, along with user-based login and role-specific permissions, to support exactly this need.

### A Searchable CV Database with Advanced Filters

Every CV processed through AdorCV becomes part of a searchable CV database. Advanced filters allow HR teams to narrow down candidate profiles based on relevant criteria, making it easier to locate specific CVs without manually browsing through the entire database. As the number of candidate profiles grows, this search capability becomes increasingly important for keeping the database usable and efficient.

### Editing and Enriching Candidate Profiles

AdorCV includes tools to edit or enrich candidate profiles directly within the database. This means candidate information doesn't remain static after upload — HR teams can update profiles as new information becomes available, keeping the database accurate over time rather than letting profiles become outdated.

### User-Based Login and Role-Specific Permissions

Access to AdorCV is managed through user-based login, meaning each person using the platform has their own individual account. On top of this, AdorCV features role-specific permissions, allowing different levels of access to be assigned depending on a user's role within the HR team.

This structure allows organizations to control who can view, edit, or manage candidate data within the platform, supporting more controlled and organized access to sensitive recruitment information. As more people within an HR team use AdorCV, this kind of access control becomes an important part of keeping the database well managed.

### How Database Management Connects to Other AdorCV Features

#### Structured Data from CV Standardization

The CVs available for search and filtering in AdorCV's database are the same CVs that were automatically converted into a unified, company-branded structure upon upload. This consistent structure is part of what makes advanced filtering effective, since every profile follows the same underlying format.

#### Supporting AI Matching

The searchable database also supports the dedicated Job Descriptions section, where AI matching compares required skills from job descriptions against the CVs stored in the database. A well-organized, searchable database is part of what makes this matching process useful in practice, since AI matching draws directly from the same structured candidate data.

#### Multilingual Documentation

AdorCV supports documents in both English and French, meaning the candidate database can include standardized profiles in either language, managed within the same searchable system rather than requiring separate databases per language.

#### Flexible Exports from the Database

Once a relevant candidate is found through search, filters, or AI matching, their profile can be exported directly as PDF, editable DOCX, or PPT, depending on how it needs to be used. This means the database is not just a storage location, but a starting point for producing ready-to-use candidate documentation.

### Why Search, Security, and Structure Matter Together

A candidate database only remains useful if it stays organized and accessible as it grows. Search and filtering make it possible to find relevant candidates quickly. Editing and enrichment tools keep the information in that database accurate. And user-based login with role-specific permissions ensures that as access to the database expands across an HR team, it does so in a controlled way. Together, these features are what allow AdorCV's database to remain both usable and appropriately managed over time.

### Benefits of AdorCV's Database and Access Controls

- **Faster candidate retrieval**, through advanced filters within the searchable CV database
- **Up-to-date candidate information**, supported by tools to edit and enrich profiles
- **Controlled access to sensitive data**, through user-based login and role-specific permissions
- **A consistent, structured database**, built on standardized CV data
